# Надёжность оценки моделей машинного обучения на малых несбалансированных онкологических данных

Репозиторий содержит программный код и результаты экспериментов к статье:

> Шырынханова Д.Ж., Карымсакова И.Б., Кожахметова Д.О., Жомартқызы Г., Есеналиева М.К. Надёжность оценки моделей машинного обучения на малых несбалансированных онкологических данных // Вестник Академии гражданской авиации.

## Данные

Используются три открытых набора данных; они загружаются кодом автоматически:

| Набор данных | Источник | Целевая переменная |
|---|---|---|
| HCC Survival | UCI Machine Learning Repository, id 423 | летальность (1 – летальный исход) |
| Cervical Cancer Risk Factors | UCI Machine Learning Repository, id 383 | результат биопсии |
| Survey Lung Cancer | Kaggle, `mysarahmadbhat/lung-cancer` | наличие рака лёгкого |

## Содержимое

| Файл | Назначение |
|---|---|
| `reviewer_experiments.ipynb` | Подготовка данных и дополнительные эксперименты: метрики с учётом дисбаланса классов, 95% доверительные интервалы показателей калибровки (бутстрэп), влияние очистки данных вне и внутри кросс-валидации |
| `reviewer1_experiments.ipynb` | Подсчёт идентичных записей в наборе Cervical Cancer по этапам, анализ чувствительности без Dx-признаков, сохранение данных для воспроизведения |
| `rev6_imbalance_metrics.csv` | PR-AUC, чувствительность, специфичность и сбалансированная точность по фолдам |
| `rev7_calibration_ci.csv` | Показатели калибровки с 95% доверительными интервалами |
| `rev8_preprocessing.csv` | AUC-ROC при очистке данных вне и внутри кросс-валидации |
| `repro/clean_*.csv` | Очищенные наборы данных (`row_id` – номер строки, используемый в файлах индексов) |
| `repro/splits_exp1_single_70_30.csv` | Индексы тестовых частей 200 однократных разбиений 70/30 (random_state 0–199) |
| `repro/splits_exp1b_cv5x5.csv` | Индексы тестовых фолдов CV 5×5 для 20 повторов (random_state 1000–1019) |
| `repro/oof_predictions_exp4.csv` | Прогнозы на тестовых фолдах, по которым рассчитаны показатели калибровки (random_state 7000) |
| `repro/cervical_duplicates_by_stage.csv` | Число идентичных записей в наборе Cervical Cancer на каждом этапе подготовки |
| `repro/cervical_dx_sensitivity.csv` | AUC-ROC и PR-AUC с Dx-признаками и без них |

## Воспроизведение

1. Откройте `reviewer_experiments.ipynb` в Google Colab.
2. Выберите «Среда выполнения → Выполнить все».

Все начальные значения генераторов случайных чисел фиксированы (`random_state`), поэтому результаты воспроизводимы.

## Программное окружение

Python 3.13, scikit-learn 1.6.1, SciPy 1.16.3, pandas, NumPy, joblib, kagglehub.
