# Надёжность оценки моделей машинного обучения на малых несбалансированных онкологических данных

Репозиторий содержит полный расчётный комплект к статье:

> Шырынханова Д.Ж., Карымсакова И.Б., Кожахметова Д.О., Жомартқызы Г., Есеналиева М.К. Надёжность оценки моделей машинного обучения на малых несбалансированных онкологических данных // Вестник Академии гражданской авиации.

## Быстрый старт

1. Откройте `full_experiments.ipynb` в Google Colab.
2. Выберите «Среда выполнения → Выполнить все» (≈ 1,5–2 ч на 2 процессорах Colab).

Блокнот с нуля воспроизводит **все** таблицы и рисунки статьи: загружает исходные данные, выполняет очистку, эксперименты 1, 1б, 1в, 2, 3, 4, анализ методологических ошибок и дополнительные метрики. Все начальные значения генераторов случайных чисел фиксированы. Результаты, полученные этим блокнотом, находятся в папке `full_results/`.

## Данные

Три открытых набора данных загружаются кодом автоматически:

| Набор данных | Источник | Целевая переменная |
|---|---|---|
| HCC Survival | UCI Machine Learning Repository, id 423 | летальность в течение года (1 – летальный исход) |
| Cervical Cancer Risk Factors | UCI Machine Learning Repository, id 383 | результат биопсии |
| Survey Lung Cancer | Kaggle, `mysarahmadbhat/lung-cancer` | наличие рака лёгкого |
